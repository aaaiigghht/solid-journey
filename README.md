# solid-journey
Java solution for decrypting intercepted messages by exploiting a vulnerability in an XOR-based encryption protocol.
## Hacking at RobberCity

Java solution for the Hacking at RobberCity challenge.

The program decrypts three intercepted hexadecimal messages using the XOR operation and converts the resulting bytes into ASCII text.

The solution demonstrates a vulnerability in the encryption protocol rather than in the XOR algorithm itself.
